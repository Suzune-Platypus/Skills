# webapp-design Skill README

**Webアプリの設計をClaudeと一緒に進めるためのSkillです。**  
要件整理から画面設計・技術スタック・データ設計・テストまで、F1〜F6のフェーズに沿って設計書を作成します。

---

## 1. このSkillでできること

- **F1〜F6の設計フェーズを対話形式で進める**（要件整理・画面設計・アーキテクチャ・データ設計・実装前確認・テスト）
- **設計書をテンプレート形式で作成する**（md / docx）
- **既存の仕様書をテンプレートと照合して不足を分析する**
- **設計書テンプレートをダウンロードする**

---

## 2. こんな人におすすめ

- **詳細設計の経験はあるが、上位設計（要件定義・画面設計など）をやったことがない人**
- **BoltなどのAI自動プログラム生成サービスを使う前に、設計を整理したい人**
- **すでに作ったアプリの仕様書をあとから整備したい人**
- **いつも同じフォーマットで設計書を作りたいチームや個人**

> 💡 Boltなどで「とりあえず動くものは作れた」けど「設計なしで作ったので後から困っている」という経験がある方に特におすすめです。

## 3. 起動の仕方

このSkillは**明示的に呼び出して使います**。チャットの最初に以下のように入力してください。

### 起動フレーズ（どれでもOK）

```
webapp-design を使って仕様書を作りたい
WEBアプリスキルを使って設計を始めたい
WEBアプリのスキルを使って既存の仕様書を確認して
```

### ファイルがある場合はまとめて渡す

既存の設計書・仕様書がある場合は、**起動フレーズと一緒にファイルを添付**するとスムーズです。

```
webapp-design を使って、この仕様書のチェックをお願いします。
（← ファイルを添付）
```

## 4. 複数日で作業する時のコツ

### 同じチャットで続ける場合
→ そのまま作業を再開できます。

### チャットを変える場合
→ **前のチャットで「引き継ぎドキュメント」を作成してから**、新しいチャットに渡してください。

引き継ぎドキュメントの作り方：
1. 前のチャットで「引き継ぎまとめを作って」と依頼する
2. 出力されたドキュメントをコピーまたはダウンロード
3. 新しいチャットで `webapp-design を使って` と一緒に渡す

> ⚠️ チャットをまたぐと作業内容は引き継がれません。引き継ぎドキュメントなしで新しいチャットを始めると、最初からやり直しになります。

## 6. このSkillの範囲と次のステップ

このSkillは**設計フェーズ専用**です。
設計が完了したら、以下の流れで実装に進めます。

### Claudeを使った開発の全体フロー

```
① 【claude.ai（チャット）】設計（このSkill）
    claude.aiとの対話を通じて設計書を作成する。
    設計が完了したらCLAUDE.mdを作成する。
    ↓
② Claude CodeにCLAUDE.mdと設計書を渡す
    CLAUDE.mdがあることでClaude Codeがプロジェクトの
    文脈を理解した状態で作業を始められる。
    ↓
③ 【Claude Code & claude.ai】実装・デバッグ
    「何を作るか」は設計書が決め、「どう作るか」を
    Claude Codeと一緒に進める。
    実装中の相談はclaude.aiのチャットで行い、
    コードの生成・修正・デバッグはClaude Codeが担当する。
    バグが出たら再現手順と期待値をセットで渡すことで、
    Claude Codeが的確に修正できる。
```

### このSkillでは対応していないこと

| 対象外 | 代替手段 |
|--------|--------|
| CLAUDE.md の作成 | 設計書完成後、通常のチャットで作成できます |
| 実際のコーディング・実装 | Claude Code を使う |
| バグ報告・修正依頼の定型化 | 通常のチャットで対応できます |
| iOSアプリ・Androidアプリの設計 | 通常のチャットで相談 |
| 静的サイト（ブログ・企業サイトなど） | 通常のチャットで相談 |
| Figma・Canvaなどのデザインツール操作 | 各ツールのサポートを参照 |
