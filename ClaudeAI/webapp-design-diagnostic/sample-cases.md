# 診断・テストに向いているアプリの規模感

## 推奨する規模感の条件

| 条件 | 目安 |
|------|------|
| 画面数 | 3〜5画面程度 |
| データ | 1〜2種類（相互参照があってもシンプルなもの） |
| ユーザー | 自分だけ or 身近な数人（認証が複雑にならない） |
| 外部API依存 | なし or 1つまで |

---

## アプリ事例

自分が「作ってみたい」と思えるものを選んでください。
以下はあくまでアイデアの例です。似たようなものでも、全く違うものでも構いません。

### 記録・参照系

| アプリ | 管理するもの |
|--------|------------|
| 読んだ本メモ | タイトル・感想・評価・読了日 |
| 観た映画ログ | 感想・おすすめ度・ジャンル |
| 推しの活動記録 | ライブ・作品・グッズ購入履歴 |
| 家族の通院記録 | 受診日・病院・処方薬 |

### 判断・選択支援系

| アプリ | できること |
|--------|----------|
| 今日のランチ候補 | 食材や気分を入力して候補を提示 |
| 買うか迷ったもの比較表 | 条件をスコアリングして比較 |
| 旅行先候補の絞り込み | 希望条件でフィルタリング |

### フロー・手順管理系

| アプリ | できること |
|--------|----------|
| 引越し準備チェックリスト | カテゴリ別・順番ありで進捗管理 |
| 料理の下ごしらえタイマー | 手順ごとに時間管理 |
| トラブルシューティングガイド | YesNo分岐で答えが変わる |

### タイマー＋記録系

| アプリ | 管理するもの |
|--------|------------|
| 作業ポモドーロ記録 | 作業内容・集中時間・振り返り |
| 子どもの成長記録 | 身長・体重・できたこと |
